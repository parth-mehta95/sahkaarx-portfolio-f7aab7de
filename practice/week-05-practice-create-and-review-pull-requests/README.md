# Practice: Create and Review Pull Requests

## Task Brief
Create feature branches, open pull requests with detailed descriptions, and practice code review workflow on your capstone project.

## Scenario
Your team uses pull requests for all changes. Create a PR for recent refactoring; request review and merge after approval.

## Deliverables
- Feature branch with 2+ commits
- Pull request with detailed description and review comments

## Success Criteria
- PR title and description clearly explain changes
- At least one peer review comment addressed
